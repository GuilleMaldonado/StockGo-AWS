# Campos de selección y captura automotriz

Las opciones ayudan a transcribir etiquetas; no prueban compatibilidad ni certificación. No se asignan valores técnicos por defecto. Siempre permite Otro / combinación para productos, valores anteriores y etiquetas que no estén listadas.

| Campo | Captura |
| --- | --- |
| Categoría, tipo según categoría | Selección; tipo admite Otro |
| Unidad de venta, base del aceite, posición, material, voltaje, fluido del aditivo | Selección con Otro |
| Viscosidad SAE | Selección dependiente del tipo; motor separado de transmisión manual/diferencial |
| API, ACEA/ILSAC | Opciones frecuentes; Otro permite múltiples clasificaciones del envase |
| Marca, proveedor, ubicación | Manual: catálogo comercial abierto |
| Número de parte, OEM, GTIN, lote, homologaciones | Manual, copiar del fabricante |
| Calibre, rosca, dimensiones, micras, bypass, dosificación, potencia | Manual con su unidad: dependen de la pieza y ficha |
| Compatibilidad por marca/modelo/año/motor | Manual, aplicaciones verificadas |
| Precio, costo, cantidades | Numérico validado |
| Vencimiento | Fecha validada AAAA-MM-DD |

Para ATF, CVT, hidráulico y grasa no se asume un grado SAE de motor; se usa la especificación que declare el fabricante, con Otro para la norma correspondiente. SAE motor y engranajes son clasificaciones diferentes. Las listas contienen ejemplos frecuentes, no todo el catálogo normativo. ACEA e ILSAC son especificaciones diferentes aunque compartan el campo existente por compatibilidad de datos.
